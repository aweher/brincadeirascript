# 🧊 Reparación de Heladeras en BrincadeiraScript

## Introducción

¡Bienvenido al mundo de la reparación de heladeras en BrincadeiraScript! 🎉 Aquí aprenderás a diagnosticar y reparar heladeras de manera divertida y eficiente.

## Diagnóstico

### Diagnóstico Básico
```brincadeira
# Diagnóstico básico
diagnostico = gracioso.heladera.Diagnostico({
    "tipo": "basico",
    "componentes": [
        "compresor",
        "evaporador",
        "condensador"
    ],
    "resultado": "OK"
})
```

### Diagnóstico Avanzado
```brincadeira
# Diagnóstico avanzado

    "tipo": "avanzado",

        "compresor",
        "evaporador",

        "termostato",
        "ventilador"
    ],
    "resultado": "OK"
})
```

### Diagnóstico Completo
```brincadeira

    "tipo": "completo",

        "compresor",
```

