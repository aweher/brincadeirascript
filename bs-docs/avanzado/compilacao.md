# 🛠️ Compilación y Plataformas Soportadas

## Introducción

¡Bienvenido al mundo de la compilación graciosa! 🎉 BrincadeiraScript está diseñado para funcionar en cualquier plataforma que tenga una palmera y un poco de sol. Aquí te explicamos todos los detalles técnicos.

## Proceso de Compilación

### Compilación Básica
```brincadeira
# Compilación simple
compilar "programa.bs" com {
    modo: "debug",
    otimizacoes: ["velocidade", "memoria"],
    saida: "programa.exe"
}
```

### Compilación Avanzada
```brincadeira
# Compilación con optimizaciones
compilar "programa.bs" com {
    modo: "release",
    otimizacoes: {
        "velocidade": "maxima",
        "memoria": "otimizada",
        "tamanho": "minimo"
    },
    flags: {
        "debug": false,
        "profiling": true,
        "gracioso": true
    },
    saida: "programa_otimizado.exe"
}
```

### Compilación Cruzada
```brincadeira
# Compilación para múltiples plataformas
compilar "programa.bs" com {
    alvos: [
        {
            "sistema": "windows",
            "arquitetura": "x86_64",
            "saida": "programa_windows.exe"
        },
        {
            "sistema": "linux",
            "arquitetura": "arm",
            "saida": "programa_linux"
        },
        {
            "sistema": "macos",
            "arquitetura": "arm64",
            "saida": "programa_macos"
        }
    ]
}
```
