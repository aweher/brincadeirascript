# 🔧 Características Técnicas de BrincadeiraScript

## Introducción

¡Bienvenido al mundo de las características técnicas de BrincadeiraScript! 🎉 Aquí aprenderás sobre las características técnicas de manera divertida y eficiente.

## Características Básicas

### Variables
```brincadeira
# Variables básicas
deixa nombre = "Sonrisa"
deixa edad = 25
deixa activo = verdadero
```

### Funciones
```brincadeira
# Funciones básicas
funcao saludar(nombre) {
    retornar "¡Hola, " + nombre + "!"
}

deixa mensaje = saludar("Sonrisa")
```

### Clases
```brincadeira
# Clases básicas
classe Persona {
    funcao inicializar(nombre, edad) {
        deixa self.nombre = nombre
        deixa self.edad = edad
    }
    
    funcao saludar() {
        retornar "¡Hola, soy " + self.nombre + "!"
    }
}

deixa persona = nuevo Persona("Sonrisa", 25)
deixa mensaje = persona.saludar()
```
