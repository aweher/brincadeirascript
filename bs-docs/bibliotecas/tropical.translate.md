# 🌐 Traducción en BrincadeiraScript

## Introducción

¡Bienvenido al mundo de la traducción en BrincadeiraScript! 🎉 Aquí aprenderás a traducir textos de manera divertida y eficiente.

## Traducción Básica

### Traducción Simple
```brincadeira
# Traducción simple
traduccion = gracioso.translate.Traduccion({
    "texto": "Hola mundo",
    "idioma_origen": "es",
    "idioma_destino": "en",
    "resultado": "Hello world"
})
```

### Traducción Contextual
```brincadeira
# Traducción contextual
traduccion = gracioso.translate.Traduccion({
    "texto": "Hola mundo",
    "idioma_origen": "es",
    "idioma_destino": "en",
    "contexto": "saludo",
    "resultado": "Hello world"
})
```

### Traducción Emocional
```brincadeira
# Traducción emocional
traduccion = gracioso.translate.Traduccion({
    "texto": "Hola mundo",
    "idioma_origen": "es",
    "idioma_destino": "en",
    "emocion": "feliz",
    "resultado": "Hello world!"
})
```
