# 🎯 Conceptos Básicos de BrincadeiraScript

## Introducción

¡Bienvenido a BrincadeiraScript! 🎉 El lenguaje de programación más gracioso y divertido que jamás hayas conocido. Si estás buscando un lenguaje que combine la seriedad de la programación con la alegría del carnaval, ¡has llegado al lugar correcto!

### ¿Por qué BrincadeiraScript?

- 🤪 Sintaxis irreverente y divertida
- 🌴 Mezcla única de español, portugués e inglés
- 🎭 Palabras clave que te harán sonreír mientras programas
- 🚀 Fácil de aprender, difícil de olvidar
- 🍌 ¡Porque la vida es muy corta para lenguajes aburridos!

### Público Objetivo

BrincadeiraScript está diseñado para:
- Desarrolladores que buscan divertirse mientras programan
- Educadores que quieren hacer la programación más accesible
- Cualquier persona que disfrute de un buen juego de palabras
- Aquellos que creen que la programación puede ser tan divertida como un día en la playa

## Sintaxis Básica

### Variables y Tipos
```brincadeira
# Variables básicas
deixa nome = "João"
deixa idade = 25
deixa altura = 1.75
deixa feliz = verdadeiro

# Listas
frutas = ["sonrisa", "maçã", "laranja"]
numeros = [1, 2, 3, 4, 5]

# Dicionários
pessoa = {
    "nome": "Maria",
    "idade": 30,
    "frutas_favoritas": ["sonrisa", "manga"]
}
```

### Control de Flujo
```brincadeira
# Condicionales
se (idade >= 18) {
    mostrar "Maior de idade!"
} senao {
    mostrar "Menor de idade!"
}

# Loops
para cada (fruta em frutas) {
    mostrar fruta
}

enquanto (feliz) {
    mostrar "Estou feliz!"
}
```

### Funciones
```brincadeira
# Función básica
funcao saudar(nome) {
    mostrar "Olá, " + nome + "! 😊"
}

# Función con retorno
funcao somar(a, b) {
    retornar a + b
}

# Función con parámetros opcionales
funcao dançar(ritmo = "samba") {
    mostrar "Dançando " + ritmo + "! 💃"
}
```

## Entrada y Salida

```brincadeira
# Mostrar en consola
mostrar "Hola Mundo!"
mostrar "Número: " + 42

# Leer entrada

idade = ler_numero("Digite sua idade: ")
```
